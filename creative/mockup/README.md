# Maqueta de Hotel Aurora

`index.html` es **un solo archivo autocontenido** (HTML, CSS y JavaScript sin dependencias de compilación). Ábrelo directamente en el navegador.

| Ruta (hash) | Pantalla |
|---|---|
| `#/` | portada: hero, la casa, habitaciones, un día en Aurora, la ciudad (mapa), disponibilidad |
| `#/habitacion/terraza` (también `alba`, `patio`, `buganvilia`) | página de habitación |
| `#/reservar` | flujo de 4 pasos: fechas, datos, pago (bloqueado), confirmación de ejemplo |

- **Guía de fotos:** botón en la franja superior; muestra el código y la medida de cada hueco de imagen (coinciden con `creative/requests/LEEME.md`).
- **Modo claro y oscuro:** sigue la preferencia del sistema.
- **Contenido ficticio:** nombres, precios, disponibilidad y servicios son de demostración. El mapa es un **esquema ilustrativo, no a escala**.
- **Avisos de portafolio:** franja superior, paso de pago y pie. El pago **no puede** avanzar.

## Procedencia y licencias
- **Íconos:** [Phosphor Icons](https://phosphoricons.com/) 2.1.1 (licencia MIT), incrustados como sprite SVG. Solo los usados.
- **Fuentes:** Bricolage Grotesque e Instrument Sans (Google Fonts, licencia OFL) pedidas a Google **solo en la maqueta**; en producción se autoalojan.
- **Imágenes:** ninguna; los huecos son degradados de color hasta que se aprueben las fotos.
