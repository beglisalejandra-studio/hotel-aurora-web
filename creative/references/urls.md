# URLs de referencia

Una URL por línea (http/https). Nota opcional tras " — ". Las líneas que empiezan por # se ignoran.
Se procesan con `npm run refs` (capturas desktop/móvil, estructura y snapshot accesible en `extracted/` y `screenshots/`).
