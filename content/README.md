# content/

Contenido editable SIN tocar código: textos de secciones, FAQs, testimonios, posts (MDX) y metadatos.

- Contenido casi estático → archivos aquí (MDX/TS tipado). Blog/edición frecuente → módulo `cms-content` (CMS headless).
- **Testimonios y cifras solo con evidencia y permiso** registrados en `PRODUCT.md`.
- El layout, los tokens, los pagos, la seguridad y las integraciones sensibles NO se editan desde aquí.
